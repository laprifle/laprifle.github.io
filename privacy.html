Privacy Policy

Music Station - last updated October 2026

Music Station is a personal project used only by its owner.

What it accesses

With the owner's permission, it uses the YouTube Data API to create and update private playlists in the owner's own YouTube account. It does not access any other user's data.

What it stores

The sign-in token is stored only on the owner's own computer and is used only to update those playlists. No data is sold, shared, or sent to anyone else.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Music Station's use of information received from Google APIs adheres to the Google API Services User Data Policy.
